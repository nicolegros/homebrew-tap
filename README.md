# homebrew-tap

Homebrew tap for [planeai](https://github.com/nicolegros/planeai).

```sh
brew install --cask nicolegros/tap/planeai
```

Already installed planeai from the DMG? Adopt the existing app instead of reinstalling it:

```sh
brew install --cask --adopt nicolegros/tap/planeai
```

`Casks/planeai.rb` is generated by the planeai release workflow from `packaging/homebrew/planeai.rb.tmpl`.
Change the template there, not this file.
